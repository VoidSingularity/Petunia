# Petunia

Petunia is the mod that aims inter-loader compatibility.

Currently, Petunia supports loading [Fabric](https://fabricmc.net) mods.

## Development
Please refer to [Berry Loader](https://github.com/VoidSingularity/berry) for more information.

To set up the build environment, run `./gradlew setup`.

To add Fabric mods for testing, you can simply put the mods into `mods/`. The buildscript will automatically add them to the runtime mods' directory.
